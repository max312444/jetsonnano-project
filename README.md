# Jetson Nano 기반 자율주행 RC 자동차 프로젝트

본 프로젝트는 NVIDIA Jetson Nano를 활용하여  
카메라 입력만으로 주행을 수행하는 자율주행 RC 자동차 시스템을 구현한 것입니다.

주행 라인을 인식하는 컴퓨터 비전 처리부터  
CNN 기반 End-to-End 딥러닝 모델 학습,  
실시간 추론 결과를 이용한 모터 제어까지  
임베디드 환경에서 자율주행 시스템의 전체 파이프라인을 직접 구현하는 것을 목표로 했습니다.

---

## 🔍 프로젝트 한눈에 보기

- **플랫폼**: NVIDIA Jetson Nano  
- **주행 방식**: 카메라 기반 라인 트래킹  
- **제어 방식**: CNN 기반 End-to-End 학습  
- **개발 목표**: 임베디드 AI 자율주행 시스템의 전체 흐름 구현  
  (센싱 → 인식 → 판단 → 제어)

## 🧠 시스템 구성

### 하드웨어

- NVIDIA Jetson Nano  
- 카메라 모듈  
- DC 모터  
- 서보 모터

## ⚙️ 주요 기능

- 카메라 영상 기반 주행 라인 인식
- 주행 이미지 데이터 수집 및 관리
- 이미지 전처리 및 학습용 데이터셋 구성
- CNN 모델 학습을 통한 조향각 예측
- 예측 결과 기반 실시간 조향 및 속도 제어
- Jetson Nano 환경에서의 실시간 추론 수행

---

## 🛠️ 개발 과정에서의 핵심 고려사항

- **조명 변화 대응**  
  다양한 환경에서도 안정적인 주행을 위해 이미지 전처리 파이프라인 개선

- **End-to-End 학습 적용**  
  규칙 기반 제어 대신, 입력부터 출력까지 하나의 모델로 학습하는 구조 채택

- **임베디드 환경 최적화**  
  Jetson Nano의 제한된 연산 자원을 고려해  
  입력 해상도 및 모델 구조를 조정

- **실시간성 확보**  
  추론 속도와 주행 안정성 간의 균형을 중점적으로 설계

---

## ⚠️ 알려진 문제 (Known Issues)

- Jetson Nano 환경에서 GPIO 핀 인식이 불안정한 경우 발생
- 특정 배터리 상태에서 DC 모터 출력이 일정하지 않은 현상
- 모델 학습 및 추론 속도가 느린 문제  
  - 향후 CUDA 및 TensorRT 기반 최적화 예정

---

## 🚀 향후 개선 사항

- TensorRT를 활용한 추론 속도 최적화
- 다양한 주행 환경에서의 데이터 추가 수집
- 장애물 인식 기능 추가
- 주행 결과 로그 수집 및 시각화 기능 구현
